# Time and Ticks

## Modelo temporal
El juego opera sobre un sistema de ticks de 1 segundo, controlados exclusivamente por el servidor.

## Reglas
- El cliente no controla el tiempo.
- No existe progreso offline automático.
- Toda acción se mide en ticks.

## Ventajas
- Anti-cheat natural
- Facilidad de auditoría
- Simplicidad conceptual
